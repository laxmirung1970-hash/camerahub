# หน้าดูกล้องแบบย่อ — Windows / เว็บ

เปิด [CameraHub บน Windows เครื่องกลาง](http://127.0.0.1:17801/) เริ่มที่ 4 ช่อง หน้าแรกเสมอ ปุ่มด้านบนเลือกโหมดได้ตรง ๆ

| โหมด | การทำงาน |
| --- | --- |
| วน 4 ภาพ | เปลี่ยนหน้าละ 4 กล้อง รวมช่องที่มีปัญหาด้วย |
| วนภาพใหญ่ | เปิดทีละกล้องแล้วเปลี่ยนไปเรื่อย ๆ จนครบ |
| ล็อก 4 ภาพ | คงกล้องชุดปัจจุบัน หรือเลือกเองจากช่องติ๊กด้านขวา |
| โฟกัส 1 ภาพ | คงกล้องเดียวจนกว่าจะเปลี่ยนเอง |

แถบหน้าอยู่ด้านบนภาพ กดลูกศรก่อน/ถัดหรือเลขหน้าได้โดยตรง แถบเลขเลื่อนแนวนอนได้เมื่อมีหลายหน้า โหมดวนเลือกช่วงเวลา 15 / 30 / 60 วินาทีได้ ขณะกำลังแก้ชื่อ จัดลำดับ เปิดรายละเอียด หรือออกไปแท็บอื่น จะพักการวน

กดภาพหรือปุ่มขยายที่ภาพเพื่อเข้าโฟกัส 1 ภาพ ปุ่มลูกศรสี่ทิศข้างชื่อเปิดรายละเอียด/ควบคุมกล้อง ใช้ Page Up/Down เปลี่ยนหน้าได้ มีเต็มจอเพื่อใช้กับจอใหญ่ การใช้รีโมตและตัวถอดรหัสของทีวีจริงยังต้องตรวจต่างหาก

## จัดกล้องด้านขวา

- สลับหมวด **หน้า 1 / หน้า 2 / …** หน้าละ 4 ตำแหน่ง
- กด **แสดงหน้านี้** เพื่อให้จอแสดง 4 กล้องของหน้านั้นแบบล็อก
- ลูกศรขึ้น/ลงที่แต่ละกล้องย้ายลำดับได้ทันที ข้ามขอบหน้าได้ และย้ายตามไปหน้าปลายทาง
- ช่อง **ย้ายไป หน้า…** ย้ายไปหน้าอื่นในตำแหน่งช่องเดียวกัน (ถ้าเป็นหน้าสุดท้ายที่ยังไม่ครบจะใช้ตำแหน่งที่มีได้)
- ลากจากจุดจับเพื่อย้ายภายในหน้าที่เห็นได้ มีปุ่มขึ้น/ลงเป็นอีกวิธีสำหรับคีย์บอร์ดและรีโมต
- ติ๊กเลือกกล้องเพื่อสร้างชุดล็อกเองสูงสุด 4 ภาพ ถ้าครบ 4 แล้วให้เอาติ๊กของเดิมออกก่อนเพิ่มตัวใหม่
- ปุ่มกรอบโฟกัสที่แต่ละรายการเปิดภาพใหญ่เฉพาะกล้องนั้น

ลำดับเก็บที่เครื่องกลาง ใช้ชื่อรุ่นและรหัสกล้องเดิม ไม่ซ่อนกล้องที่ออฟไลน์ การกรองห้องหรือค้นหาชื่อจะจัดเฉพาะกล้องที่เห็น โดยเก็บตำแหน่งของกล้องนอกตัวกรองไว้

## เปลี่ยนชื่อโดยไม่เปิด Edit

คลิกพิมพ์ลงบนชื่อได้ทั้งใต้ภาพและในรายชื่อด้านขวา **Enter หรือคลิกออก** เพื่อบันทึก **Esc** ยกเลิก ชื่อว่างไม่ถูกบันทึก หากบันทึกไม่สำเร็จมีข้อความที่ช่องเดิม ผู้ชมที่ไม่มีสิทธิ์เจ้าของเห็นชื่อแบบอ่านอย่างเดียว

## ผลตรวจ

- TypeScript + Vite production build ผ่าน และ Vitest **12 ข้อ** ผ่าน รวมทดสอบวนครบ 17 รายการ, วนภาพเดียว, ล็อกคง ID หลังจัดลำดับ, เลือกชุดเอง, รายการว่าง/ลดจำนวน และย้ายข้ามหน้าภายใต้ตัวกรอง
- ตรวจ Chrome ของผู้ใช้จริง: หน้าใหม่เริ่ม 4 ช่อง เปลี่ยนหน้า และเปิด 4 วิดีโอจริงบนหน้าที่สองได้
- แก้ชื่อกล้องทดสอบบนหน้าแรก ชื่อปรากฏทั้งใต้ภาพและรายการ เปิดหน้าใหม่แล้วยังคงอยู่ แล้วคืนชื่อเดิมเรียบร้อย ระหว่างเปลี่ยนชื่อวิดีโอทั้งสี่เป็น readyState 4 และ currentTime เดินต่อ (ประมาณ 77 → 90 วินาที)
- ทดสอบย้ายกล้องจากช่องแรกหน้า 2 ขึ้นไปช่องสุดท้ายหน้า 1 แล้วลงกลับ เก็บลำดับเดิมหลังตรวจ
- ตรวจโฟกัสหลังย้ายข้ามหน้า ยังอยู่ที่ลูกศรขึ้นของกล้องเดิม ตรวจช่องย้ายไปหน้าปลายทาง (หน้า 2 → 3 → 2) และคืนลำดับแล้ว
- เลือกชุดล็อกข้ามหน้าได้จริง: Mi 360° / กล้องถ่ายวีดีโอ3 / C300 Dual / H2 รวม 4 ช่อง แล้วโฟกัส H2 ได้ 1 ช่อง ทดสอบ Esc ยกเลิกชื่อและคืนหน้าปกติ
- โหมดวนภาพใหญ่เปลี่ยนจากกล้องลำดับ 5 ไป 9 ตามเวลา โหมดโฟกัสคง H2 ระหว่างตรวจส่วนอื่น โหมดวน 4 เปลี่ยนจากหน้า 1 ไปหน้า 2 ที่ 15 วินาที
- ตรวจ viewport CSS **390×844** ไม่มีเนื้อหาล้นแนวนอน ใช้แถบเลื่อนและกล้อง 4 ช่องได้ เป็นการจำลอง viewport บน Chrome ไม่ใช่ iPhone จริง
- บันทึกภาพและการตรวจรอบสุดท้ายใน `.cache/compact-monitor-2026-11-04*` ใช้เป็นหลักฐานภายใน มีภาพกล้องจริง ไม่รวมในชุดเผยแพร่

ใช้ React state ตัวเดียวกำหนดโหมด/หน้า/กล้องที่โฟกัส เก็บตัวเล่นด้วย camera ID เดิม การเปลี่ยนชื่อหรือจัดชุดไม่สร้างวิดีโอทุกตัวใหม่ ไม่มีการแก้ backend, บัญชีกล้อง หรือเฟิร์มแวร์ในรอบนี้

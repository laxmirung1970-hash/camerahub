# Xiaomi C300 Dual: แสดงสองเลนส์ — 4 พฤศจิกายน 2026

แก้บน Windows live ที่ [CameraHub](http://127.0.0.1:17801/) แล้ว กล้อง C300 Dual ทั้งสองเครื่องมีช่องภาพแยก **เลนส์ 1/2** และ **เลนส์ 2/2** เลือกดูพร้อมกันในชุด 4 ภาพ วนภาพ หรือโฟกัสภาพใหญ่ได้เหมือนช่องอื่น

## วิธีเลือกดู

1. ค้นหา `C300 Dual` ที่รายชื่อด้านขวา จะเห็น 4 ช่องภาพจากอุปกรณ์สองเครื่อง
2. กด **แสดงหน้านี้** หรือ **ล็อก 4 ภาพ** เพื่อคงภาพทั้งสี่มุม
3. ถ้าต้องการเพียงเครื่องเดียว ให้เลือกสองช่องที่ชื่อเครื่องเดียวกัน โดยดูป้ายเลนส์ใต้ชื่อประกอบ
4. เปลี่ยนชื่อแต่ละช่องได้ทันทีจากหน้าแรก และย้ายลำดับแยกกันได้ตามเดิม

ช่องใหม่ถูกวางถัดจากช่องเดิมเมื่อเพิ่มครั้งแรก การซิงก์ครั้งต่อไปไม่ย้ายกลับหากเจ้าของจัดลำดับใหม่ ไม่ต้องกรอกรหัสผ่านหรือเชื่อมบัญชี Xiaomi ซ้ำเพื่อเพิ่มเลนส์ที่สองของกล้องที่ผูกไว้แล้ว

ทะเบียนเดิม 17 รายการเพิ่มอีก 2 **ช่องภาพ** เป็น 19 รายการ จำนวนอุปกรณ์จริงไม่ได้เพิ่มขึ้น การตรวจรอบนี้เป็นของ C300 Dual ทั้งสองเครื่อง ไม่ใช่การตรวจกล้องทั้งระบบซ้ำ

## การเปลี่ยนแปลง

- ใช้ model ที่ตรวจจริง `chuangmi.camera.072ae2` เป็นรายการรองรับสองเลนส์ ไม่เดาจำนวนเลนส์จากชื่อที่เจ้าของแก้ได้
- เก็บรหัสช่องหลักเดิม เพิ่มรหัสช่องเลนส์ 2 ที่คงเดิมแม้เปลี่ยนชื่อ/IP/โทเคน และเปิดภาพด้วย `channel=2` ส่วนเลนส์หลักไม่ส่งพารามิเตอร์ channel
- เก็บ `parentId`, `lens`, `lensCount` เป็นข้อมูลช่องภาพ ชื่อ กลุ่ม รายการโปรด ผลตรวจ และตำแหน่งของแต่ละช่องแยกกัน
- เพิ่มช่องจากทะเบียนเดิมตอนเริ่มแอป และจากการค้นหา/ซิงก์ Xiaomi รอบถัดไป ป้องกันรายการซ้ำแม้ต้นทางส่งช่องเดิมซ้ำ
- บันทึกทะเบียนพร้อมลำดับช่องใหม่ใน SQLite transaction เดียว มีการทดสอบ rollback เมื่อเขียนฐานข้อมูลไม่สำเร็จ
- URL ต้นทางและข้อมูลบัญชียังเข้ารหัสในเครื่องกลาง ไม่ส่งผ่าน API รายชื่อกล้อง
- ช่องเลนส์ 2 ไม่อ้างว่ามีมอเตอร์แยก การตรวจภาพไม่ติ๊กยืนยันเสียง/หมุนแทนเจ้าของ ใช้ช่องหลักสำหรับการควบคุมมอเตอร์ที่เคยตรวจไว้

ใช้ gateway/Windows UDP relay ที่ตรึงเวอร์ชันเดิม ไม่มีการเปลี่ยน firmware ของกล้อง โดย go2rtc เวอร์ชันนี้มีการรองรับช่องที่สองอยู่แล้ว: [เอกสารต้นทาง ณ commit ที่ใช้งาน](https://github.com/AlexxIT/go2rtc/blob/b5948cfb25404cc5cb37b166ecaa2dca20b11d4b/internal/xiaomi/README.md#configuration)

## ผลตรวจ

| อุปกรณ์ | เลนส์ 1 | เลนส์ 2 |
|---|---|---|
| Xiaomi Smart Camera C300 Dual 2 | ภาพบริเวณพื้นโรงฝึก/ประตู | ภาพบริเวณตู้เก็บของ/บันได |
| Xiaomi Smart Camera C300 Dual | ภาพรถและประตูโรงจอดรถระยะใกล้ | ภาพมุมกว้างโรงจอดรถ/โครงหลังคา |

- รับทั้งสี่ stream พร้อมกันผ่าน gateway จริง แล้วถอดรหัสด้วย FFmpeg ได้ครบ ภาพต่างมุมกันจริง
- Chrome หน้าเว็บจริงเปิดทั้งสี่ช่องพร้อมกันได้ `readyState=4`, 848×480 ในโหมดประหยัดข้อมูล และเวลาวิดีโอเดิน
- ตรวจภาพผ่านปุ่มใน CameraHub สำหรับช่องใหม่ ไม่ใช้เพียงผลพบอุปกรณ์หรือการล็อกอินแทนผลวิดีโอ
- ซิงก์ Xiaomi อัตโนมัติรอบจริงเวลา 10:30 สำเร็จ ยังมี 19 ช่องภาพ ไม่มีรายการซ้ำ จากนั้นเริ่ม app container ใหม่ ตรวจภาพทั้งสี่เลนส์เปิดได้อีกครั้ง
- ลองตัวเลือกคุณภาพสูงของช่องเลนส์ 2 ทั้งสองเครื่องแล้วเล่นได้ แต่ความละเอียดที่ได้รับในรอบนี้ยัง 848×480 จึงยังไม่รับรองความละเอียดสูงสุดของกล้อง
- Go test และ go vet ผ่าน; Vitest 13 tests และ TypeScript/Vite build ผ่าน ครอบคลุมการซิงก์ซ้ำ, IP เปลี่ยน, ชื่อและลำดับแยก, ผลตรวจอิสระ, การเก็บข้อมูลลับ และการกั้นผู้ไม่ลงชื่อเข้าใช้
- ตรวจเทียบทะเบียนเดิม: ชื่อ กลุ่ม รายการโปรด รูปแบบเล่นภาพ ผลยืนยันของเจ้าของ และลำดับสัมพัทธ์ทั้ง 17 รายการยังอยู่ครบ

ภาพ/วิดีโอที่ใช้ตรวจและ SQLite snapshot เป็นข้อมูลส่วนตัว อยู่ใน `.cache/dual-lens-private/` ซึ่งถูกตัดออกจาก Docker build และชุดส่งมอบ ไม่รวมใน release สาธารณะ

# ติดตั้งแอปกล้องบนทีวี (Mi TV Stick) — คู่มือพนักงาน

**ต้องมี:** รีโมต Mi Stick · คอมเครื่องกลาง (เครื่องที่เปิดระบบกล้อง) · ทีวีกับคอมต่อ **Wi-Fi บ้านเดียวกัน** · เวลาประมาณ 15 นาที

## ส่วนที่ 1: ที่ทีวี (ทำครั้งเดียว)

1. เปิดทีวี เลือกช่อง HDMI ที่เสียบ Mi Stick
2. หน้า Home กดรีโมตไปที่ **⚙ Settings** (มุมขวาบน) กด OK
3. เลือก **Device Preferences** → **About**
4. เลื่อนลงหา **Build** แล้วกด OK **7 ครั้งติดกัน** จนขึ้นข้อความ "You are now a developer"
5. กด Back 1 ครั้ง จะเห็นเมนูใหม่ **Developer options** → เข้าไป
6. หา **USB debugging** → เปิดเป็น **ON** → ถ้ามีหน้าต่างถาม กด **OK**
7. กด Home → **⚙ Settings** → **Network & Internet** → กดชื่อ Wi-Fi ที่ต่ออยู่ → **จดเลข IP address** (หน้าตาแบบ 192.168.x.x)

## ส่วนที่ 2: ที่คอมเครื่องกลาง

8. ดูมุมขวาล่างของจอ ต้องมี **ไอคอนวาฬ (Docker)** ถ้าไม่มี เปิดโปรแกรม Docker Desktop แล้วรอ 1 นาที
9. เปิดโฟลเดอร์ `G:\กล้องวงจรปิด` → ดับเบิลคลิก **Install-TV.cmd**
10. หน้าต่างสีดำถาม IP → พิมพ์เลขจากข้อ 7 → กด **Enter**
11. **หันไปดูทีวีทันที** จะขึ้นหน้าต่าง "Allow USB debugging?" → ติ๊ก **Always allow from this computer** → กด **OK** (มีเวลา 90 วินาที)
12. รอจนหน้าต่างสีดำขึ้นคำว่า **"สำเร็จ"** แอป CameraHub TV จะเปิดบนทีวีเอง → กดปุ่มใดก็ได้เพื่อปิดหน้าต่างสีดำ

| หน้าต่างสีดำขึ้นว่า | ให้ทำ |
| --- | --- |
| ติดต่อทีวีไม่ได้ | ตรวจเลข IP (ข้อ 7), Wi-Fi เดียวกัน, USB debugging เป็น ON (ข้อ 6) แล้วเริ่มข้อ 9 ใหม่ |
| ทีวีไม่ยอมรับคอมเครื่องนี้ | เริ่มข้อ 9 ใหม่ แล้วกด OK บนทีวีให้ทัน |
| เปิด Docker Desktop ก่อน | ทำข้อ 8 แล้วเริ่มข้อ 9 ใหม่ |

## ส่วนที่ 3: เชื่อมทีวีกับกล้อง

13. บนทีวี ช่องที่อยู่เครื่องกลาง ใช้รีโมตพิมพ์ **URL เครื่องกลาง:** `____________________________` (เจ้าของเขียนให้) พิมพ์ให้ตรงทุกตัว → เลือก **รับรหัสจับคู่**
14. ทีวีขึ้น **รหัสจับคู่** (ใช้ได้ 5 นาที)
15. ที่คอม เปิด Chrome เข้า <https://camerahub-sigma.vercel.app> → กด **⚙** → แท็บ **ทีวีและอุปกรณ์** → ดูว่ารหัสตรงกับบนทีวี → กด **อนุมัติ**
    ถ้าหน้าเว็บขอรหัสผ่าน ให้เจ้าของกดอนุมัติจากมือถือแทน
16. ทีวีขึ้นภาพกล้อง 4 ช่อง **เสร็จ**

## ใช้งานรีโมต

- ลูกศร = เลือกกล้อง · OK = ดูภาพใหญ่ · Back = กลับ 4 ช่อง
- ครั้งต่อไป: กด Home → เลือกแอป **CameraHub TV**

## หลังติดตั้งเสร็จ

- กลับไปข้อ 5–6 แล้วปิด **USB debugging** เป็น **OFF** (ปลอดภัยกว่า) ถ้าต้องอัปเดตแอปภายหลัง ค่อยเปิดใหม่แล้วทำส่วนที่ 2 อีกครั้ง

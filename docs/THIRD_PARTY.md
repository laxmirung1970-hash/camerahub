# Third-party components

Local patches on the pinned go2rtc source: `xiaomi-motor-replies.patch` normalizes command replies, `gateway-startup.patch` adds readiness metadata, and `windows-udp-relay.patch` optionally carries CS2 datagrams through an authenticated Windows relay. Their checksums are verified in `deploy/go2rtc.Dockerfile`. The relay uses Node.js built-in modules only; the current Windows machine already has Node installed. It is a private transport workaround, not an official Xiaomi or go2rtc feature. See [local verification and limitations](LIVE_CHECK_2026-11-03.th.md).

- **AndroidX Media3**, Apache-2.0; Android SDK tooling and Kotlin/Gradle build tooling are downloaded from Google/Maven/Gradle official distribution services. Android dependency versions are pinned in Gradle scripts.
- **Robolectric 4.14.1**, MIT, test dependency only. Used to exercise native Android View focus/navigation and render synthetic UI previews; not included in the release APK. It does not test physical TV video decoders or camera motors.
- **FFmpeg**, Alpine package (LGPL/GPL as configured with x264), used as a separate executable in the gateway image. Source packages and license references are available from the matching [Alpine v3.22 repository](https://pkgs.alpinelinux.org/packages?name=ffmpeg&branch=v3.22). Rebuild recipes are included; when redistributing outside personal use, preserve all notices and the corresponding upstream source/build offer.

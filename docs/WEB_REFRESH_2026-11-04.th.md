## ที่เปลี่ยน

- **ธีมใหม่** ชาร์โคล `#0f1013` ตัวอักษรงาช้าง `#ecebe6` สีเน้นส้มอิฐ `#e2714e` (ชุดเดียวกับแอปทีวี 1.1.0) วงโฟกัสสีเหลืองอำพัน `#f6c453` ให้เห็นชัดจากรีโมต ฟอนต์ IBM Plex Sans Thai ขนาดฐาน 14–18px ตามจอ บรรทัดสูง 1.65 สำหรับไทย
- **หน้าเดียว** แถบบน 48px (โลโก้ · โหมด · นาฬิกา · ตั้งค่า · ออก) + ภาพ 4 ช่องเต็มพื้นที่ + รายชื่อกล้องด้านขวา 360px ไม่มี sidebar ซ้าย หัวข้อใหญ่ footer หรือแถบล่างมือถืออีก
- **ปุ่มที่เหลือ** โหมด 4 ปุ่ม (วน 4 / วนภาพใหญ่ / ล็อก 4 / โฟกัส 1) · ‹ หน้า x / y › · เวลาสลับ · เต็มจอ · ต่อช่อง: ป้าย LIVE/DEMO + ปุ่มเสียง · คลิกภาพเปิดรายละเอียด

- **รายชื่อกล้อง** เป็นรายการเดียวมีหัวข้อ "หน้า 1 / 4" ทุก 4 ตัว ปุ่ม "แสดง" ต่อหน้า ติ๊กล็อก 4 ภาพ ◎ โฟกัส ↑ ↓ ย้ายข้ามหน้าได้ ลากด้วยเมาส์บนจอกว้าง (ตัด select "ย้ายไปหน้า" และแท็บแบ่งหน้าออก) ช่องค้นหา + เลือกกลุ่ม + ↻ ค้นหากล้องใหม่
- **ตั้งค่า** 3 แท็บ เชื่อมกล้อง / ทีวีและอุปกรณ์ / ระบบและสำรอง (ตัดแท็บ "เตรียมใช้งานจริง" ออก เนื้อหาอยู่ใน `docs/PREPARE.th.md`) เปิดตั้งค่าแล้วภาพ 4 ช่องไม่หยุด
- **มือถือ** ภาพเรียงแนวตั้ง 1 ช่อง แนวนอน 2×2 รายชื่อกล้องซ่อนหลังปุ่ม "รายชื่อกล้อง (N)" · **ทีวี** ตรวจจาก user agent หรือ `?tv=1` ตัวอักษร 20px ปุ่ม 52px วงโฟกัสหนาขึ้น ลูกศรเลื่อนโฟกัสได้ทุกปุ่ม/ช่อง/select

## บั๊กที่แก้

- นาฬิกาเคยทำให้ทั้งแอป render ใหม่ทุกวินาที → แยกเป็น `Clock.tsx`
- ตัวเล่นวิดีโอ: WebRTC→MSE→HLS เคยซ้อนกันเมื่อ WebRTC ล้มระหว่างรอ ทำให้ throw แล้วเริ่ม MSE สองรอบ และ timer ถูกเขียนทับ → เขียนใหม่เป็น `transport.ts` มี generation counter + cleanup set ต่อ transport + deadline ต่อ transport (5/12/20 วิ) + watchdog เดียว
- สถานะกล้องกระพริบ online↔error ทุก 15 วิ เคยทำให้ภาพที่เล่นอยู่ถูกเปิดใหม่ → ใช้ `usable()` เป็น boolean แทน `camera.status`
- Session หมดอายุเคย toast ทุก 15 วิ ไม่กลับหน้า login → `onUnauthorized` พากลับหน้า login ทันที
- หน้าต่างใดก็ตาม (รวมตั้งค่า) เคยปิดภาพทั้ง 4 ช่องแล้วเปิดใหม่ → เหลือเฉพาะเปิดรายละเอียดบนจอแคบ
- ปุ่มหมุน: stop เคยยิงซ้ำ 2–3 ครั้งต่อการปล่อย และ move อาจไปถึงหลัง stop → คิวคำสั่งเรียงลำดับ ส่ง stop เฉพาะเมื่อเคยส่ง move
- Toast ไอคอนถูกเสมอแม้เป็นข้อผิดพลาด · `api()` พังเมื่อได้ 204 · Modal Tab หลุดออกทาง textarea/summary · Escape ปิดเต็มจอกับ modal พร้อมกัน · Safari native HLS ไม่มี error listener · localStorage ไม่มี try/catch
- ลบ `Camera.lastSeen/region`, `System.uptimeSeconds/fieldTested`, export ที่ไม่ใช้ และ lucide icon ที่ไม่ใช้

## ขนาดโค้ด

`web/src` จาก TSX 3,750 + CSS 3,937 บรรทัด (4 ไฟล์ CSS ขัดกันเอง 342 สีฮาร์ดโค้ด) → TSX ≈ 2,080 + CSS 1,100 บรรทัดไฟล์เดียวใช้ CSS variable ทั้งหมด `App.tsx` 2,335 → 247 บรรทัด เพิ่ม ESLint + `noUnusedLocals` ทดสอบ Vitest 13 → 24 ข้อ (เพิ่ม transport, api, Modal, Clock)

## เชื่อม Vercel

`web/src/api.ts` อ่าน `VITE_API_BASE` (ว่าง = โดเมนเดียวกันตามเดิม) ถ้าตั้งค่า จะล็อกอินแบบ Bearer token เก็บใน localStorage ส่งใน header, hls.js `xhrSetup` และ WebSocket subprotocol `["bearer", token]` ฝั่ง backend ต้องมี `APP_ALLOWED_ORIGINS` (ทำแล้วช่วงบ่าย ดู `docs/BACKEND_REFRESH_2026-11-04.th.md`) ไฟล์ `web/vercel.json` + `web/.env.example` พร้อมแล้ว

**อัปเดตทีวี 3 พฤศจิกายน:** native Android TV ปรับดีไซน์และการเดินรีโมตแล้วใน APK 1.1.0 ดู [รายงานทีวีพร้อมภาพ native renderer](TV_UI_REVIEW_2026-11-03.th.md) และ [คู่มือ](TV_GUIDE.th.md) ข้อความท้ายรายงานนี้ที่บอก native TV ยังไม่ปรับ เป็นสถานะรอบก่อนหน้า ยังไม่ตรวจทีวีจริง

**อัปเดตหลังทำต่อเวลา16:15:** ใช้หน้ารวมใหม่4ภาพวนครบทุกสถานะเป็นค่าเริ่มต้น ไม่ต้องเลือกเอง มีallviewเป็นตัวเลือก แก้rename/paging/ดูเดี่ยว/ขยายเต็มพื้นที่และตรวจChromeจริงแล้ว ดู [ผลตรวจหน้ารวมล่าสุด](MONITOR_GUIDE.th.md) รายการด้านล่างบางข้อเป็นดีไซน์รอบแรกและถูกแทนที่โดยหน้ารวมใหม่

## ดีไซน์ที่ใช้งาน

- พื้นขาวนวล แถบเมนูชาร์โคล สีหลักส้มอิฐ แทนโทนเขียวเดิม ใช้ฟอนต์ไทยที่ติดตั้งในแอป ไม่เรียกฟอนต์ภายนอก
- จัดลำดับหน้าเป็นกล้องของคุณ → ผลตรวจโดยย่อ → ภาพสด → รายการเลือกกล้อง ภาพไม่ถูกครอป (16:9, object-fit: contain)
- เมื่อเลือกเพียงหนึ่งกล้องจะใช้ความกว้างพื้นที่ภาพทั้งหมด ปุ่มเสียง/ขยาย/โปรดชัดขึ้น
- ป้าย LIVE ผูกกับสถานะเล่นของ Player จริง ไม่อาศัยแค่ข้อมูลว่ากล้องเคยเชื่อมต่อได้; กล้องจำลองยังติดป้าย DEMO ชัดเจน
- มือถือมีปุ่มเลือก/เปลี่ยนกล้องและปุ่มกลับไปดูภาพ รวมถึงแถบนำทางด้านล่าง เคารพ prefers-reduced-motion
- หน้ารวมใหม่รวมกล้องทุกสถานะ เริ่ม4ภาพวนครบทุกกล้องและแสดงข้อผิดพลาดในช่องนั้น มีตัวเลือกทุกช่องพร้อมกันและจำค่าที่ผู้ใช้เลือก โหมดทุกช่องยังไม่เสถียรเท่า4ภาพในการตรวจเครื่องปัจจุบัน
- ปรับหน้าลงชื่อเข้าใช้ หน้ารายละเอียด หน้าตั้งค่า และไอคอน/สี PWA ให้สอดคล้องกัน; service worker shell cache v2
- ฟอร์ม Tapo เปิดส่วนเพิ่มด้วย IP เป็นหลัก เหลือช่องบัญชีชุดเดียวที่เห็นทันที ย้ายการค้นหาอัตโนมัติไปส่วนขยาย เพื่อลดความสับสนเรื่องกรอกบัญชีสองตำแหน่ง

## สิ่งที่ตรวจแล้ว

- TypeScript และ Vite production build ผ่าน ทั้งบน Windows และใน Docker amd64
- เปิดธีมใหม่กับ Tapo92 บน Chrome เห็นภาพสดจริงก่อนการตรวจรอบสุดท้าย ไม่ติดต่อ Tapo91 ในการตรวจดีไซน์
- แยกโครงการ Docker `camerahub-design-qa` ใช้ฐานข้อมูลและกล้องจำลองล้วนสำหรับตรวจ UI: 4 วิดีโอ H264 640px เล่นจริงผ่าน MSE (readyState 4 ทั้งสี่)
- ตรวจ desktop และ responsive viewport: อ่านค่า CSS viewport 390×844, document scrollWidth 372px (พื้นที่ viewport หัก scrollbar) ไม่มี horizontal overflow
- ทดลองค้นหาชื่อกล้อง, ปุ่มเลือกกล้อง/กลับไปภาพบนมือถือ, ยกเลิกเลือกครบทั้งหมดและรอผ่านรอบ refresh, เปิด/ปิด settings dialog และแท็บเชื่อมต่อ
- ดูภาพหน้าจอ desktop, sign-in และ mobile; การจับ screenshot modal ใน mobile บางรอบ timeout ของ browser จึงยืนยันโครงสร้าง/ข้อความด้วย AX ไม่อ้างว่า screenshot ทุกหน้าผ่าน

## ขอบเขต

ไม่ได้เปลี่ยนบัญชี ข้อมูลกล้อง เฟิร์มแวร์ NAS หรือ backend API และไม่ใช้ผลสาธิตรับรองภาพกล้องจริงอื่น ๆ หน้าจอมือถือเป็นการจำลอง viewport ใน Chrome ยังไม่ทดสอบ iPhone/Android จริง

Windows live image อัปเดตแล้ว ส่วน ARM64 tar, ZIP, APK และ SHA256 ของ releases ยังเป็นชุดก่อนการแก้ UI รอบนี้ ต้องสร้าง/ตรวจชุดติดตั้งใหม่ก่อนนำไปติดตั้งเครื่องอื่น แอป Android TV แบบ native ยังไม่ได้ปรับดีไซน์รอบนี้

# เตรียมเมื่อคุณมีเวลา

ตอนนี้ยังไม่ต้องเปลี่ยนการตั้งค่ากล้องหรือ NAS และไม่ต้องส่งรหัสผ่านในแชต

## อุปกรณ์และสิทธิ์

- [ ] เข้า DSM ของ **Synology DS223** ได้ด้วยบัญชีที่ติดตั้งแพ็กเกจและสร้างโฟลเดอร์ได้
- [ ] ทราบเวอร์ชัน DSM และติดตั้ง/เปิด Container Manager ได้ หากเครื่องเสนออัปเดต DSM ให้พิจารณาแยกจากการทดลองแอป ไม่บังคับอัปเดตอัตโนมัติ
- [ ] ทราบพื้นที่ว่างและงานอื่นที่ NAS ใช้อยู่ เพื่อวัด RAM/CPU ร่วมกัน
- [ ] เข้า Xiaomi Home ด้วยบัญชีที่มองเห็นกล้องทั้ง **14 ตัว** (C300 7, C300 Dual 2, m360 1080p 1, C302 4) และทราบ Region ที่เลือก
- [ ] บัญชี Xiaomi มีรหัสผ่าน พร้อมรับ SMS/อีเมลยืนยัน หากปกติเข้าด้วย Google/Apple อาจต้องตั้งรหัสผ่านของ Xiaomi ก่อน โดยเจ้าของดำเนินการเอง
- [ ] เข้าแอป Tapo และเห็น **C520WS ทั้ง 2 ตัว** พร้อมเปิด Camera Account
- [ ] กล้องและ NAS อยู่ในเครือข่ายที่ติดต่อถึงกันได้ ไม่ใช่ Guest Wi-Fi หรือเครือข่ายที่แยกอุปกรณ์
- [ ] เข้าเราเตอร์เพื่อดูรายการ IP หรือจอง DHCP ให้กล้องได้ หากจำเป็น
- [ ] มี iPhone, Android และ Windows สำหรับตรวจรับ
- [ ] มี Mi TV/Android TV พร้อมทราบรุ่นและเวอร์ชัน Android (APK กำหนดขั้นต่ำ Android 8)
- [ ] พร้อมติดตั้ง Tailscale บน NAS และอุปกรณ์ที่ดูจากนอกบ้าน รวมทีวีเมื่อใช้ที่อยู่ Tailscale
- [ ] เตรียมอินเทอร์เน็ตมือถือสำหรับทดสอบนอกบ้านจริง โดยปิด Wi-Fi ของมือถือในช่วงทดสอบ

## ข้อมูลกล้องที่หาได้โดยไม่ถอดกล้อง

บันทึกชื่อรุ่นและจำนวนล่าสุดไว้ใน [รายการกล้องจริง](CAMERAS.th.md) แล้ว รวม 16 เครื่อง เมื่อสะดวกดูหน้าข้อมูลอุปกรณ์ในแอปเดิม: ชื่อกล้อง model ID เฟิร์มแวร์ IP และ Region ถ้าหาได้ โดยเฉพาะ m360 camera (1080p) ที่ชื่อยังไม่ระบุรุ่นแน่นอน ใช้ข้อมูลนี้เฉพาะตั้งค่า/ตรวจความเข้ากันได้ การเชื่อม Xiaomi จะพยายามดึงรุ่นให้อัตโนมัติ จึงไม่ต้องจดทั้งหมดก่อนเริ่ม

## ลำดับครั้งถัดไป

1. สำรองค่าที่เกี่ยวข้อง แล้วติดตั้งชุด ARM64 บน DS223 ในโฟลเดอร์ใหม่
2. ตั้ง Tailscale Serve/HTTPS และบัญชีเจ้าของแอป
3. ทดลอง Tapo หนึ่งตัว: ภาพ SD/HD เสียง ทิศทางหมุน และการหยุด
4. ทดลอง Xiaomi หนึ่งตัว: บัญชี/Region ภาพ เสียง การหมุนแบบทีละก้าว และผลเมื่ออินเทอร์เน็ตหลุด
5. ทดลอง Xiaomi แต่ละรุ่น รวม C300 Dual ทั้งสองเลนส์ แล้วขยายครบ 16 เครื่อง พร้อมตารางผลรายกล้องใน `camera-inventory.csv` ไม่ทำเครื่องหมายว่ารองรับจากรายชื่อเพียงอย่างเดียว
6. ทดสอบ 1–4 ภาพ หลายผู้ชม การเพิ่มกล้องใหม่ รีสตาร์ต NAS และวัดทรัพยากร
7. ติดตั้ง APK จับคู่ทีวี ตรวจรีโมต ภาพ/เสียง และการดูผ่านเครือข่ายมือถือ

หากบางรุ่นไม่รองรับ จะสรุปปัญหาเฉพาะตัวก่อนตัดสินใจเรื่องตัวเชื่อมหรืออุปกรณ์เพิ่ม ไม่มีการจัดซื้อหรือแฟลชเฟิร์มแวร์ให้เอง
